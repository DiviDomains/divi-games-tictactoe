Play key

This is a testnet play key, made by this page and kept in this browser's storage. It only holds testnet GOLD, which has no value. Anyone who can read this browser's storage can use it. Export it to play from another device, or import one you already have.

Play a bot

The bot sees the whole game tree, so it never loses. Before each move it tells you what it will play, why, and what it expects back. You approve it, pick another move for it, or let it play on a timer. Bot tables have no stake, so you need no GOLD. On your own open table, press Let the bot join; if that table has a stake, the bot matches it, and since it never loses, a stake against it can only cost you.

The bots live in this browser and move only while this page is open. Close it mid-game and the game waits for you; a bot never claims a timeout.
